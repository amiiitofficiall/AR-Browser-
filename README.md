## Download

Latest APK: **[Releases](../../releases/latest)** → download `AR_Browser_1_0.apk`

### Install
1. Download the APK from Releases.
2. Enable **Install from unknown sources** for your browser/file manager.
3. Open the APK and tap **Install**.

## Requirements

- Android [min version, jaise 5.0+]
- Internet permission

## Build from Source

### Using Sketchware Pro
1. Download the `.swb` backup from this repo.
2. Open Sketchware Pro → **Restore project** → select the file.
3. Build and run.

### Using Android Studio
1. Clone the repo:
   ```
   git clone https://github.com/<username>/AR-Browser.git
   ```
2. Open the folder in Android Studio.
3. Sync Gradle and run.

> Note: The project uses Java 1.7 and XML because of Sketchware Pro limitations.
